Start every response with the answer or the result in one plain sentence. Add detail only when it changes what the reader will do next.

## Conventions

- Prefer short paragraphs to nested bullet lists.
- Define a term the first time you use it.
- When a command or path matters, put it in a code block so it can be copied.
