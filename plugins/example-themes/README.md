# example-themes

A minimal colour theme.

## What it shows

A theme file in `themes/example-dusk.json` using the custom theme format: a `name`, a `base` preset and a map of `overrides`. The manifest's `experimental.themes` key points at the directory.

## Try it

```bash
claude --plugin-dir ./plugins/example-themes
```

Start a session with the command above, run `/theme` and pick "Example Dusk". Plugin themes are read-only, and editing one saves a copy to your own themes directory.
